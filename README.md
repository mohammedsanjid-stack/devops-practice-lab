# DevOps Practice Lab

A practical DevOps project demonstrating CI/CD automation using Jenkins, automated Python testing with pytest, Docker image builds, and publishing images to Docker Hub.

## Technologies
- Jenkins
- Git and GitHub
- Python and Flask
- pytest
- Docker
- Docker Hub

## CI/CD Pipeline
1. Checkout source code from GitHub.
2. Install Python dependencies.
3. Run automated tests using pytest.
4. Build a Docker image.
5. Tag and push the image to Docker Hub using Jenkins credentials.

## Docker Image
Docker Hub repository: `mhdsanjid/devops-mastery-app`

Images are published with build-number and `latest` tags.
